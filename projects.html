CreatorsBridge

A live marketplace connecting local content creators with local businesses for paid collaborations. Businesses post collaboration requests with a budget and niche; creators browse by city and send offers. Contact details stay hidden until a business explicitly accepts. This is enforced at the API level, not just the UI. We also run a companion LinkedIn Page to help creators land their first collaboration.

React + Vite Tailwind CSS Node.js / Express MongoDB JWT Auth
Live Site GitHub LinkedIn Page

WashAtComfort

A doorstep car-wash booking platform for Pune societies, built from a problem I'd personally lived through years of washing cars myself. Customers send car photos, get a fixed quote on WhatsApp within 2 hours, and a verified local washer comes to their own parking spot.

HTML / CSS / JS Google Apps Script Cloudinary WhatsApp API
